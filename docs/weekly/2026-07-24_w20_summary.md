# W20 durable release gate

The useful increment this week is a real boundary between local model output and
Cloud release state. Java still owns execution; Cloud now verifies and promotes
twenty content-addressed objects, persists three actual Java jobs plus twelve
case release records, and rejects stale lease writers.

Ten case cards expose playable replay audio as provisional evidence. Two rejected
cases remain blocked and publish no audio. There is no human-reviewed winner.
The Mainbase repository is currently `fd1422d`, while the frozen artifacts retain
their original `0334abe` lineage; both roles are stored instead of being collapsed
into one misleading commit field.

The release status follows the real k6 result. Local SQLite durability and
fencing are demonstrated, but they are not a distributed database or
exactly-once system. Production Prometheus, Alertmanager, Grafana import, object
storage, Kubernetes leases, GitHub Actions provenance, and signed attestation
remain explicitly unverified.
